# Баримт бичиг · Орчуулга (ямар ч файл → 日本語 / English → PDF/Word)

Байгууллагад зориулсан веб. Word, Excel, PowerPoint, PDF, OpenDocument, RTF, CSV,
зураг — ямар ч баримтаа оруулж, засварлаж, **Япон** болон **Англи** хэл рүү
орчуулаад, **PDF** эсвэл **Word** болгож гаргана.

## Боломжууд
- **Оруулах (import):** доорх хүснэгтийг үзнэ үү. Өргөтгөл нь буруу/байхгүй байсан ч
  файлын эхний байтуудаас (magic bytes) төрлийг нь таньдаг.
- **Засах:** тод/налуу, гарчиг, жагсаалт, зэрэгцүүлэлт, зураг чирж оруулах — веб дээрх засварлагч
- **Албан толгой:** байгууллага/огноо/дугаар/гарын үсэг бүхий бэлэн загвар нэг товчоор
- **Орчуулах:** Эх ↔ 日本語 ↔ English гурвыг хажуу хажууд нь; "→ 2 хэл" нэг товчоор хоёуланг нь
- **Автомат хадгалалт:** засвар бүр браузерт хадгалагдана, дахин нээхэд draft сэргэнэ
- **Дизайн темплейт:** ✨ Темплейт товчоор өнгөт дизайнтай баримт (уулзалтын материал, албан тоот, тайлан) сонгож, [хаалтан доторх] хэсгүүдийг засаад орчуулж, гаргана.
- **Гаргах:** Word (.docx) татах, **PDF — Chromium (WYSIWYG)** — засварлагч дээр харагдаж буй дизайн (өнгө, карт, диаграм, хүснэгт) яг байгаагаар нь PDF болно. Монгол ү/ө, Япон үсэг зөв (Noto фонт).

### Дэмжигдэх файлын төрлүүд

| Төрөл | Өргөтгөл | Юу орж ирэх вэ |
|-------|----------|----------------|
| Excel | `.xlsx .xlsm .xltx` | Хүснэгт бүрэн: **зураг бүр өөрийн нүдэндээ**, баганын өргөн, мөрийн өндөр, нийлүүлсэн нүд, фонт, өнгө, хүрээ, холбоос |
| Excel (хуучин) | `.xls .xlsb` | Хүснэгтийн утга (зураг дэмжигдэхгүй) |
| Word | `.docx .docm` | Текст, хүснэгт, зураг, формат (браузерт эх хэвээр нь) |
| Word (хуучин) | `.doc` | Текст, догол мөр (зураг ороогүй) |
| PowerPoint | `.pptx .pptm` | Слайд бүр: гарчиг, жагсаалт, хүснэгт, зураг, илтгэгчийн тэмдэглэл |
| PDF | `.pdf` | Эх байрлалаар нь засварлаж болох текст давхарга |
| OpenDocument | `.odt .ods .odp` | Текст/хүснэгт/слайд + зураг |
| RTF | `.rtf` | Догол мөр, тод/налуу, хүснэгт, шингэсэн зураг |
| Хүснэгт текст | `.csv .tsv` | Хүснэгт |
| Текст | `.txt .md .html .json .xml .log` | Markdown нь гарчиг/жагсаалт/хүснэгт болж хөрвөнө |
| Зураг | `.png .jpg .gif .webp .bmp` | Тайлбар бичих зайтайгаар шигтгэнэ |

## Ажиллуулах
```bash
npm install
cp .env.example .env      # тохиргоо
npm start                 # → http://localhost:3000
```

## Орчуулгын провайдер тохируулах
`.env` файлын `TRANSLATE_PROVIDER`-ийг сонгоно:

| Утга | Тайлбар | Хэрэгтэй зүйл |
|------|---------|----------------|
| `demo` | API key шаардахгүй, туршихад (жинхэнэ орчуулга хийхгүй) | — |
| `claude` | Албан бичгийн өнгө аяс, форматыг хамгийн сайн хадгална | `ANTHROPIC_API_KEY` |
| `deepl` | Япон–Англи орчуулгад маш сайн | `DEEPL_API_KEY` |
| `google` | Хямд, олон хэл | `GOOGLE_TRANSLATE_API_KEY` |

Орчуулга нь HTML-ийг бүтнээр нь API руу илгээхгүй — зөвхөн **текст зангилаануудыг**
салгаж, багцлан илгээгээд буцаагаад байрлуулна. Үүний үр дүнд:

- зургийн data URI (олон MB) API руу огт явахгүй → хурдан, хямд, хязгаарт хүрэхгүй;
- хүснэгт, өнгө, дизайн **100% хэвээрээ** үлдэнэ;
- том баримт багцалж явдаг тул хариу тасрахгүй (нэг багц алдвал тэр хэсэг нь эх
  хэлээрээ үлдэж, бусад нь орчуулагдана).

Провайдер солиход код өөрчлөх шаардлагагүй — зөвхөн `.env`.

## Бүтэц
- `server.js` — Express сервер, API замууд
- `lib/parse.js` — нэгдсэн диспетчер: төрөл таних + файл → HTML
- `lib/xlsx.js`, `lib/xlsx-style.js` — Excel-ийн өөрийн уншигч (зургийн anchor, styles.xml)
- `lib/pptx.js`, `lib/odf.js`, `lib/rtf.js`, `lib/legacy-doc.js`, `lib/markdown.js` — бусад форматууд
- `lib/xml.js`, `lib/opc.js` — XML уншигч ба Office-ийн zip багцын туслахууд
- `lib/translate.js` — залгаж/сольж болдог орчуулга (claude/deepl/google/demo)
- `lib/export.js` — HTML → Word (.docx)
- `public/` — веб интерфейс (засварлагч, 3 багана, гаргац)

## Тэмдэглэл
- **Скан хийсэн (зураг) PDF** — текст агуулаагүй бол OCR шаардлагатай (одоогоор ороогүй; хэрэгтэй бол `tesseract.js`-ээр нэмж болно).
- **PDF гаргац** нь headless **Chromium (Puppeteer)**-ээр серверт үүснэ. Засварлагчийн HTML/CSS-ийг яг байгаагаар A4 болгож рэндэрлэнэ (WYSIWYG). Дизайн темплейтийн өнгө/карт/диаграм бүрэн гарна.
- **Фонт:** Docker дотор `fonts-noto-core` (Латин+Кирилл, ү/ө орно) + `fonts-noto-cjk` (Япон). Тиймээс □ асуудалгүй.
- **Локал:** `npm install` үед Puppeteer өөрийн Chromium-ийг татна. Docker дээр apt-ийн `chromium`-ийг ашиглана (`PUPPETEER_EXECUTABLE_PATH`).
- **Excel-ийн зураг** — `xl/drawings/*.xml` доторх anchor-ыг уншиж, **яг тухайн нүдэнд нь**
  байрлуулна (өмнө нь хүснэгтийн доор овоорч байсан). LibreOffice шаардахгүй.
- **Өргөн хүснэгт** — PDF үүсгэхэд агуулгын өргөнөөс хамаарч A4 босоо/хэвтээ автоматаар
  сонгогдож, хуудас бүр өөрийн масштабаар багтана (бүх баримтыг нэг дор жижигрүүлэхгүй).
- **Фонтын метрик** — Excel-ийн баганын өргөн нь Calibri/Cambria-гийн хэмжээгээр тооцогддог тул
  Docker дотор `fonts-crosextra-carlito`, `fonts-crosextra-caladea` (яг ижил метриктэй) суулгасан.
  Ингэснээр текст багананд багтахгүй тасрах асуудал гарахгүй.
- **Том баримт** — зурагтай баримт 3–5MB-аас хэтэрвэл браузерын автомат хадгалалт (localStorage)
  унтарна. Ажлаа PDF/Word болгож татаж авахыг анхаарна уу.
